## One small interface

A provider adapter implements two methods.

```ts
type Model = {
  complete(input: ModelInput): Promise<ModelOutput>;
  stream(input: ModelInput): AsyncIterable<ModelToken>;
};
```

`Agent.run()` calls `complete()`. `Agent.streamEvents()` calls `stream()` and forwards its provider tokens and metadata before parsing the complete action envelope. Implement both methods when building an adapter.

```ts
import type { Model } from "stateweave";

export const model: Model = {
  async complete(input) {
    const response = await provider.generate({
      system: input.system,
      prompt: input.prompt,
      signal: input.signal
    });
    return { text: response.text, usage: response.usage };
  },

  async *stream(input) {
    yield { type: "token", token: (await this.complete(input)).text };
  }
};
```

Keep adapters thin. Do not rebuild transcripts or summarize state inside the adapter. `input.prompt` is already the compiled causal view.

## Included adapters

```ts
import { AnthropicModel, createModelFromEnv, MockModel } from "stateweave";
```

- `MockModel`: deterministic tests, no provider.
- `AnthropicModel`: a thin HTTP adapter, no Anthropic SDK dependency.
- `createModelFromEnv()`: picks mock or Anthropic from environment variables.

## What the agent receives

The provider gets:

```txt
input.prompt   the compiled causal view
input.system   the action protocol and tool list
signal         an abort signal
parameters     adapter-specific
```

The provider still sees a linear token sequence. That sequence is a temporary compilation of graph state, not stored chat history.

```ts
for await (const event of agent.streamEvents("Inspect the workspace")) {
  if (event.type === "model_token") process.stdout.write(event.token);
  if (event.type === "model_metadata") console.log(event.metadata);
  if (event.type === "final") console.log(event.result.finalAnswer);
}
```

`stream()` and `streamText()` remain convenience methods that yield the accepted
final answer after the complete action has been parsed and committed. Provider
streaming is observable through `streamEvents()`; partial action text is not
executed before the envelope is complete.
