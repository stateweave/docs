## Run one complete turn

The npm package is awaiting its initial authenticated publication. Until `stateweave` is available from npm, run the SDK from source. This path is complete and requires no API key.

## 1. Build the SDK

```bash
git clone https://github.com/stateweave/sdk-typescript.git
cd sdk-typescript
corepack enable
pnpm install
pnpm test
pnpm build
```

StateWeave requires Node.js 22 or newer.

## 2. Run a deterministic agent

Create `quickstart.mjs` in the repository root:

```js
import { promises as fs } from "node:fs";
import { Agent, MockModel } from "./dist/index.js";

const agent = new Agent({
  model: new MockModel(),
  tools: [],
  enforceCompletionEvidence: false
});

const first = await agent.run("My name is Ada.");
console.log(first.finalAnswer);
console.log(first.metadata.engine); // causal-weave-v3
console.log(first.state.nodes.map(({ kind, parents }) => ({ kind, parents })));

const second = await agent.run("What is my name?");
console.log(second.finalAnswer); // Your name is Ada.
```

Run it:

```bash
node quickstart.mjs
```

`MockModel` is deterministic. It proves the agent loop, state commit, and cross-turn continuity without sending data to a provider.

## 3. Persist and resume

`AgentState` is plain validated data. Store the first run’s state wherever your application stores user-owned data.

```js
await fs.writeFile("agent-state.json", JSON.stringify(first.state));

const state = JSON.parse(await fs.readFile("agent-state.json", "utf8"));
const resumed = new Agent({
  model: new MockModel(),
  tools: [],
  enforceCompletionEvidence: false,
  state
});

await resumed.run("Continue from the saved state.");
```

Import validation rejects altered content identities, missing parents, invalid sequence order, and broken frontier references.

## 4. Connect Anthropic

```js
import { Agent, AnthropicModel } from "./dist/index.js";

const model = new AnthropicModel({
  apiKey: process.env.ANTHROPIC_API_KEY,
  model: process.env.ANTHROPIC_MODEL,
  maxTokens: 4096,
  temperature: 0
});

const agent = new Agent({
  model,
  tools: [],
  enforceCompletionEvidence: false
});

const result = await agent.run("Explain the difference between state and context.");
console.log(result.finalAnswer);
```

```bash
ANTHROPIC_API_KEY=... \
ANTHROPIC_MODEL=... \
node quickstart.mjs
```

Do not expose provider keys in browser code. Run model calls on a server boundary.

## What just happened

One `run()` call:

1. created a `system` root and `goal`;
2. compiled a bounded causal view;
3. called the model;
4. parsed one ordinary action;
5. recorded the inference and answer with exact read-set parents;
6. committed a new `AgentState` only after success.
