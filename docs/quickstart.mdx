## One complete turn

The npm package is not published yet. This path builds the SDK from source and needs no API key.

<img src="/images/causal-weave-overview.webp" alt="An immutable causal graph, a bounded view of a few nodes, and one model action" loading="lazy" />

## 1. Build the SDK

```bash
git clone https://github.com/stateweave/sdk-typescript.git
cd sdk-typescript
corepack enable
pnpm install
pnpm build
```

Requires Node.js 22 or newer.

<Note>
  The initial npm publication is still pending.
  Do not run `pnpm add stateweave` until it exists. This source path works today.
</Note>

## 2. Run a deterministic agent

Create `quickstart.mjs` in the repo root:

```js
import { promises as fs } from "node:fs";
import { Agent, MockModel } from "./dist/index.js";

const agent = new Agent({ model: new MockModel(), tools: [] });

const first = await agent.run("My name is Ada.");
console.log(first.finalAnswer);            // Nice to meet you, Ada.
console.log(first.metadata.engine);        // causal-weave-v3
console.log(first.state.nodes.map((n) => n.kind));

const second = await agent.run("What is my name?");
console.log(second.finalAnswer);           // Your name is Ada.
```

`MockModel` needs no provider. It proves the loop, the commit, and cross-turn memory.

## 3. Persist and resume

`AgentState` is plain data. Store it where you store user-owned data.

```js
import { promises as fs } from "node:fs";
import { Agent, MockModel } from "./dist/index.js";

await fs.writeFile("state.json", JSON.stringify(first.state));

const state = JSON.parse(await fs.readFile("state.json", "utf8"));
const resumed = new Agent({ model: new MockModel(), tools: [], state });

await resumed.run("Continue from the saved state.");
```

When you import state, StateWeave checks identities, parent order, sequence, timestamps, resource keys, and frontier references. Bad state is rejected, not repaired.

## 4. Connect a provider

```js
import { Agent, AnthropicModel } from "./dist/index.js";

const model = new AnthropicModel({
  apiKey: process.env.ANTHROPIC_API_KEY,
  model: process.env.ANTHROPIC_MODEL,
  maxTokens: 4096,
  temperature: 0
});

const agent = new Agent({ model, tools: [] });
const result = await agent.run("Explain state versus context.");
console.log(result.finalAnswer);
```

Keep provider keys on the server. Never expose them to the browser.

## What one call does

<Accordion>
  <AccordionItem title="Expand: what happened">
    1. create a `system` root and a `goal`;
    2. compile a bounded causal view with a deterministic big-brain map, peripheral summaries, focus detail, and timeline;
    3. call the model (or stream provider tokens through `streamEvents()`);
    4. parse one ordinary action;
    5. record the inference and answer with exact read-set parents;
    6. commit a new `AgentState` only after success.
  </AccordionItem>
</Accordion>
