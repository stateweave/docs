## The public surface

Import from the package root.

```ts
import { Agent, AnthropicModel, type AgentState } from "stateweave";
```

## State

```ts
type AgentState = {
  version: 1;
  nodes: Array<{
    id: string;
    kind:
      | "system" | "goal" | "inference" | "semantic"
      | "tool_call" | "tool_result" | "resource"
      | "verification" | "answer" | "protocol_error";
    parents: string[];
    payload: unknown;
    createdAt: string;
    sequence: number;
    resourceKey?: string;
  }>;
  frontier: string[];
};
```

`AgentState` is public. The internal causal node aliases are not separate package-root exports.

## Semantic configuration

```ts
type SemanticNodeType = { name: string; description: string };

// payload shape when a causal node has kind: "semantic"
type SemanticPayload = {
  type: string;
  key: string;
  content: unknown;
};
```

`SemanticNodeType` is exported. `SemanticPayload` documents the runtime shape; it is not a separate package-root type.

## Model

```ts
type ModelInput = {
  prompt: string;
  frame?: GraphFrame;
  mode?: "graph_ops" | "text";
  parameters?: ModelParameters;
  system?: string;
  signal?: AbortSignal;
};

type Model = {
  complete(input: ModelInput): Promise<ModelOutput>;
  stream(input: ModelInput): AsyncIterable<ModelToken>;
};
```

The public `Agent` calls `complete()` with `mode: "text"`, a compiled `prompt`, and no `frame`. The optional frame and `graph_ops` mode stay for the low-level utilities.

Adapter exports:

- `MockModel`
- `AnthropicModel`
- `anthropicConfigFromEnv()`
- `createModelFromEnv()`
- `collectModelText()`
- `estimateStateWeaveTokens()`

## Progress and traces

```ts
type AgentProgress = {
  iteration: number;
  phase: "context" | "model" | "tool" | "final" | "retrying";
  modelCalls: number;
  toolCalls: number;
  totalInputTokens: number;
  outputTokens: number;
  detail: string;
  contextTokens?: number;
  prompt?: string;
  state?: AgentState;
  graph?: StateGraph;
  rawModelOutput?: string;
  action?: "tool" | "final" | "invalid";
  tool?: string;
  error?: string;
};

type AgentTraceStep = {
  step: number;
  nodeIds: string[];
  prompt: string;
  contextTokens: number;
  rawModelOutput: string;
  action: "tool" | "final" | "invalid";
  tool?: string;
  error?: string;
};
```

`AgentStreamEvent` is a discriminated union of `metadata`, `progress`, and `final`.

## Visualization graph

```ts
type StateGraph = { nodes: GraphNode[]; edges: GraphEdge[] };
```

`Agent.getGraph()` returns this view. `graphToMermaid()` renders it with no graph-database or UI dependency.

## Low-level graph utilities

The package also exports GraphFrame-era utilities: graph creation, clone, fork, append-input, validation, serialization, GraphOps schemas, parsing, projection, and `GraphFrame`, `GraphOp`, `StateGraph`, and trace types.

<Note>
  Legacy compatibility.
  These utilities remain exported for historical artifact compatibility and
  explicit graph work. The public `Agent` uses Causal Weave v3, not GraphFrame
  or the SWX GraphOps loop. There is no second public graph-frame agent class.
</Note>

For exact signatures, the package root is the authority:
[`src/index.ts`](https://github.com/stateweave/sdk-typescript/blob/development/src/index.ts).
